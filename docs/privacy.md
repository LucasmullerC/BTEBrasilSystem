# BTE Brasil Privacy Policy

**Last Updated: August 21, 2026**

This Privacy Policy explains how the **BTE Brasil** Discord application and the **BTEBrasilSystem** Minecraft integration ("BTE Brasil", "the Application", "we", "our", or "us") access, use, store, and protect information when providing integration between the Build The Earth: Brasil Minecraft server and Discord community.

The BTE Brasil application supports account linking, player applications, profiles, ranks, claims, achievements, permissions, Discord role synchronization, slash commands, and communication between supported Minecraft and Discord channels.

Source code:

https://github.com/LucasmullerC/BTEBrasilSystem

## 1. Information We Access and Process

Depending on the features a user interacts with, the Application may access or process the following information.

### Discord account information

We may process:

- Discord user ID;
- Discord username when required to display or identify a user;
- whether a user is a member of the BTE Brasil Discord server;
- Discord roles assigned to a server member; and
- information necessary to perform Discord permission and role synchronization operations.

### Minecraft account and BTE Brasil information

We may store information associated with the user's participation in the BTE Brasil Minecraft server, including:

- Minecraft UUID;
- association between a Minecraft UUID and Discord user ID;
- player application status;
- player profile information;
- ranks and progression;
- points and completed builds;
- claims;
- achievements and awards; and
- other information required to operate BTE Brasil Minecraft features.

### Discord message content

The Application uses Discord message content only where necessary to provide configured Discord-to-Minecraft chat integration.

When a user sends a message in a Discord channel configured for Minecraft chat integration, the message may be processed so that it can be relayed to the corresponding Minecraft chat.

Message content may also be processed for functionality such as formatting, attachments, stickers, configured filters, account-link requirements, and role-based chat permissions.

The Application does not use message content for advertising, behavioral profiling, marketing, or artificial intelligence or machine-learning training.

BTEBrasilSystem does not maintain a dedicated database for creating Discord message histories.

Operational Minecraft or Discord integration logs may contain information related to relayed messages when necessary for server operation, security, troubleshooting, or abuse prevention. Such information is retained only for as long as reasonably necessary for those purposes.

## 2. How We Use Information

Information accessed through Discord or generated through the Minecraft server is used only as necessary to provide and maintain BTE Brasil functionality.

This includes:

- linking Minecraft and Discord accounts;
- verifying whether a linked user belongs to the BTE Brasil Discord server;
- checking roles and permissions;
- synchronizing Discord roles with Minecraft progression or project status;
- displaying player profiles, achievements, claims, ranks, and leaderboards;
- processing player applications;
- operating administrative and moderation functionality;
- responding to Discord slash commands;
- providing configured Discord and Minecraft chat integration;
- maintaining the security and reliability of the service; and
- investigating technical problems or abuse.

We do **not** sell user information.

We do **not** use Discord API data for advertising or marketing.

We do **not** create advertising or behavioral profiles using Discord data.

We do **not** use Discord message content or other Discord API data to train artificial intelligence or machine-learning models.

## 3. Data Storage and Retention

Some information must remain stored for longer than 30 days in order to provide persistent BTE Brasil functionality.

For example, a user's Discord ID may remain associated with their Minecraft UUID while their BTE Brasil account and Minecraft/Discord integration remain active.

We retain Discord API data only for as long as it remains necessary for the functionality described in this Privacy Policy.

When information is no longer required for the Application's functionality, it may be deleted.

Operational logs are retained only for as long as reasonably necessary for server administration, security, troubleshooting, and abuse prevention.

## 4. Data Storage and Security

BTE Brasil services are hosted on **Oracle Cloud Infrastructure (OCI)**.

Application data stored on the server is protected by infrastructure-level encryption at rest provided by Oracle Cloud Infrastructure. OCI Boot Volumes and Block Volumes use AES-256 encryption at rest.

Administrative access to the server and its management systems is restricted through authenticated accounts and is limited to authorized BTE Brasil administrators.

We use reasonable technical and administrative safeguards intended to protect stored data from unauthorized access, modification, disclosure, destruction, or loss.

No online system can guarantee absolute security, but we work to maintain protections appropriate to the information processed by the Application.

## 5. Sharing of Information

We do not sell Discord API data or other user information.

Information may be processed by infrastructure or service providers when necessary to operate the Application, such as our hosting provider.

Our current infrastructure provider is **Oracle Cloud Infrastructure (OCI)**.

Information may also be disclosed when required by applicable law, regulation, legal process, or a valid governmental request.

We do not share Discord API data with third parties for advertising, marketing, or unrelated commercial purposes.

## 6. Data Deletion and User Requests

Users may request access to, correction of, or deletion of information associated with their Discord account and BTE Brasil integration.

Requests can be submitted through the support ticket system available in the official BTE Brasil Discord server:

https://discord.com/invite/w6GC56W445

Any member of the community can open a private support ticket through the **SUPPORT** section of the server. The resulting ticket channel is accessible only to the requesting user and authorized BTE Brasil staff.

When submitting a privacy or deletion request, users should indicate that the request concerns their BTE Brasil application data and provide enough information for us to identify the relevant Discord and/or Minecraft account.

We may request reasonable information to verify that the person making the request controls the relevant Discord or Minecraft account.

After verification, we will delete or modify applicable Discord API data when requested, unless retention is required by applicable law or the information remains legitimately necessary to handle an active security, abuse, or legal matter.

Deleting the association between a Discord account and Minecraft account may disable functionality that depends on account linking, including role synchronization, profiles, applications, achievements, claims, or other integrated features.

Support tickets are closed after the request has been handled. Closed ticket conversations are not used by BTE Brasil for advertising, profiling, or AI/ML training.

## 8. Children's and Teen Users' Privacy

Users must meet the minimum age requirements applicable to the platforms and services they use, including Discord and Minecraft.

We do not intentionally use Discord API data for advertising or profiling of children or teenagers.

## 9. Changes to This Privacy Policy

We may update this Privacy Policy when the Application's functionality, data practices, infrastructure, or applicable requirements change.

When the policy is updated, the **Last Updated** date at the top of this page will also be changed.

Material changes affecting how Discord API data is collected or used will be reflected in this policy before or when the relevant functionality is introduced.

## 10. Contact

For privacy questions, requests to access or correct stored information, or requests to delete Discord API data associated with your account, please contact the BTE Brasil team through the support ticket system in our official Discord server:

https://discord.com/invite/w6GC56W445

To contact us:

1. Join the official BTE Brasil Discord server.
2. Open the **SUPPORT** section.
3. Click **"Criar um Ticket" / "Create a Ticket"**.
4. Explain that your request concerns privacy, access, correction, or deletion of your BTE Brasil data.

The resulting support channel is private and accessible only to the requesting user and authorized BTE Brasil staff.
